- [Find a paper](#find-a-paper)

- [contributing.md](contributing.md) - how to add or fix a paper
- [metadata.json](metadata.json) - machine-readable index

## Find a paper

1. Open your branch in [Branches](#branches).
2. Open the semester, then the subject folder.
3. Open the PDF you need.

To search across all branches, open [INDEX.md](INDEX.md) and use your browser's find command (`Ctrl+F` or `Cmd+F`) for the subject or paper name. Older files may keep their original names, so try a nearby subject name if an exact match does not appear.

## Syllabus

Full syllabus PDFs are in [Syllabus](Syllabus/), grouped by branch. The folder has 144 PDFs. Open your branch folder to see its syllabus files.

## File Naming

Papers usually follow the format `Subject-Session-Year.pdf`:

- `Engineering Mathematics-W-2023.pdf` - Winter 2023
- `Data Structures-S-2024.pdf` - Summer 2024
- `Digital Electronics.pdf` - Year unknown

Older files may not follow this format. Search by subject name in [INDEX.md](INDEX.md) when a filename looks unfamiliar. See [contributing.md](contributing.md) for the full naming convention.
